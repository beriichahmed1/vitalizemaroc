## RISKS & MITIGATION

| Risk | Mitigation |
|------|-----------|
| Low confirmation rate (<85%) | Premium packaging + day-1 follow-up + guarantee |
| High CPA (>50 MAD) | Refine audience targeting, test new creative angles |
| Speace integration delays | Have manual order forwarding ready as backup |
| Product quality issues | Source from certified suppliers only, test batches |
| Ad account bans (Meta) | Use compliant wellness language, avoid medical claims |
| Inventory stockouts | Start conservative (5 units), reorder weekly based on sales |
| Payment gateway issues | Have backup gateway (PayFort/Telr) ready |
